Аннотация
Какие уравнения описывают вычисления в мозге — не то, что он делает, а как
он это делает? В работе систематически извлечены пять фундаментальных
математических формализмов теоретической нейробиологии, пригодных для
прямого переноса в код: (1) дендритные вычисления — кабельное уравнение,
NMDA-спайки и кальциевые плато, двухслойная модель пирамидного нейрона
и трёхфакторное правило Урбанчика–Сенна; (2) предиктивное кодирование и
вариационная 
свободная 
энергия 
Фристона, 
Рао–Балларда 
и
Уиттингтона–Богача; 
(3) 
теория 
эффективного 
кодирования 
—
сбалансированные 
сети, 
разрежённое 
кодирование 
и 
независимые
компоненты; (4) аттракторная динамика — сети Хопфилда, современные
плотные ассоциативные памяти, непрерывные аттракторы и хаотическая
блуждающая динамика; (5) теория критичности — ветвящиеся процессы и
нейрональные лавины. Для каждого механизма выдержан единый формат:
базовое уравнение, переменные состояния (что именно хранит нейрон и
синапс), численный метод решения, связь с обучением (локальные правила
против глобального градиента), вычислительная сложность и возможности её
факторизации, а также проверяемые ссылки на первоисточники 1954–2024 гг.
Показано, что пять формализмов складываются в единый вычислительный
«стек»: дендриты — локальный субстрат, свободная энергия — цель обучения,
эффективное кодирование — формат представления, аттракторы — память и
навигация, 
критичность 
— 
режим 
максимальной 
динамической
чувствительности. Для всех пяти механизмов приведён работоспособный
псевдокод на PyTorch, готовый к адаптации.

1. Введение
Человеческий мозг содержит порядка 86 миллиардов нейронов и
порядка 1014 синапсов [1], а весь этот вычислительный конгломерат
потребляет примерно 20 Вт — мощность слабой лампочки накаливания
[2]. 
На 
этом 
скромном 
бюджете 
выполняются 
задачи, 
которые
современные глубокие сети решают ценой киловатт и мегаватт:
распознавание сцены за 150 миллисекунд, навигация, планирование и
непрерывное обучение на потоке данных без эпох и датасетов. При этом
отдельные нейроны — устройства с шумом, частотой разрядов около 10
Гц и латентностью миллисекунды, казалось бы, лишённые ресурсов для
«серьёзной» 
математики. 
Парадокс 
разрешается 
только 
одним
способом: мозг не имитирует универсальную машину фон Неймана, а
реализует вычисления физикой собственной среды — градиентами
напряжения, регенеративными нелинейностями мембраны, балансом
возбуждения и торможения и коллективной динамикой больших сетей.
Нейронаука накопила колоссальный корпус данных о том, что
делает мозг: какие структуры активны при каких задачах, какими
свойствами обладают рецептивные поля, где локализована рабочая
память. Но инженеру, желающему построить систему, обучающуюся
как мозг, требуются уравнения: какие переменные состояния хранит
нейрон, по какому закону они эволюционируют, как из динамики
рождается правило обучения и какова цена вычисления. Настоящий
обзор адресован именно этому дефициту. Из обширной литературы по
теоретической нейробиологии извлечены математические формализмы,
каждый из которых удовлетворяет трём критериям: (а) он описывает
базовый вычислительный механизм, а не феноменологию; (б) он записан
явными уравнениями, допускающими численное решение; (в) он
порождает локальное правило обучения, реализуемое в биологически
правдоподобной сети.
Отобранные формализмы выстраиваются в пять уровней, которые
в совокупности образуют «стек» мозговых вычислений. Активные
дендриты 
— 
субстрат 
локальных 
нелинейных

превращающих каждый нейрон в двухслойную машину вывода (раздел
2). Предиктивное кодирование и принцип свободной энергии —
глобальная целевая функция, спускающаяся до синапсов в форме
локально 
вычислимых 
ошибок 
предсказания 
(раздел

import torch
class TwoCompartmentNeuron(torch.nn.Module):
    """Двухкомпартментная модель (ур. 4-7): дендрит прогнозирует сому.
    Динамика — явный Эйлер; пластичность — трёхфакторное правило (7)."""
    def __init__(self, n_in, dt=1e-3):
        super().__init__()
        self.dt = dt
        self.Cm, self.gL, self.EL = 1.0, 0.05, -70.0   # единицы СГС упрощены
        self.gD = 0.1                                # связь dendrite -> soma

=== PAGE 12 ===
МАТЕМАТИЧЕСКИЕ ОСНОВАНИЯ ВЫЧИСЛЕНИЙ В МОЗГЕ
12
        self.phi_max, self.beta, self.theta = 100.0, 1.0, -50.0
        self.w = torch.nn.Parameter(0.01 * torch.randn(n_in))
        self.register_buffer('V_D', torch.tensor(self.EL))
        self.register_buffer('V_S', torch.tensor(self.EL))
    def phi(self, V):                                 # соматический gain
        return self.phi_max / (1.0 + torch.exp(-self.beta * (V - self.theta)))
    def step(self, x, I_S=0.0):
        """Прямой шаг: интеграция (4)-(5) явным Эйлером."""
        I_D = (self.w * x).sum()                      # синаптический вход дендрита
        self.V_D = self.V_D + self.dt / self.Cm * (
            -self.gL * (self.V_D - self.EL) + I_D)
        self.V_S = self.V_S + self.dt / self.Cm * (
            -self.gL * (self.V_S - self.EL) + self.gD * (self.V_D - self.V_S) + I_S)
        return self.phi(self.V_S)
    def plasticity(self, x, S_t, eta=1e-3):
        """Правило (7):  dw_i = eta * [S - phi(V*_D)] * dV_D/dw_i.
        dV_D/dw_i ~ x_i*dt/Cm — вклад синапса i в дендритный потенциал."""
        V_star = (self.gL * self.EL + self.gD * self.V_D) / (self.gL + self.gD)  # (6)
        err = S_t - self.phi(V_star)                 # постсинаптическая 'ошибка'
        dV_dw = x * self.dt / self.Cm                # локальный градиент ветви
        with torch.no_grad():
            self.w += eta * err * dV_dw              # три фактора, все локальны
        return err

предиктивный слой от одного прохода backprop. Факторизация —
стандартные трюки разреженных/низкоранговых W⊤.
3.3. Локальные правила, эквивалентность backprop и
дендритная реализация
Уиттингтон и Богач показали [24], что предиктивная сеть с
обновлениями (13) точно совпадает с backpropagation в специальном
пределе: (а) нелинейность f линеаризована (f(x) ≈ x), (б) обратные веса
связаны транспонированием с прямыми, (в) вывод по (12) доведён до
стационара. Тогда стационарные значения ошибок εl пропорциональны
δ backprop, и локальные обновления (13) воспроизводят градиент
послойно — глобальный градиент возникает как стационарная точка
локальной динамики. Ослабление условий (обратные связи без точной
симметрии, нелинейные f) даёт приближённое совпадение, чего на
практике достаточно: предиктивные сети решают MNIST/CIFAR-задачи

import torch
class PredictiveCodingNet(torch.nn.Module):
    """hPC-сеть (ур. 11-13): состояния x_l уточняются градиентным спуском
    по энергии ошибок E = 0.5 * sum ||eps_l||^2; обучение локальное."""
    def __init__(self, sizes, f=lambda z: torch.tanh(z)):
        super().__init__()
        self.f = f
        self.W = torch.nn.ModuleList([          # нисходящие предсказания W_l
            torch.nn.Linear(sizes[i+1], sizes[i], bias=False)
            for i in range(len(sizes)-1)])
        self.sizes = sizes
    @torch.no_grad()
    def infer(self, data, T=25, eta=0.05):
        """Вывод: цикл по (12) при фиксированных весах. Возвращает ошибки."""
        L = len(self.sizes)
        x = [None] * L
        eps = [None] * (L-1)
        x[0] = data                                   # низ иерархии фиксирован
        for l in range(1, L):                         # стартовая инициализация
            x[l] = torch.zeros_like(torch.randn(*data.shape[:-1], self.sizes[l]))
        for _ in range(T):
            for l in range(L-1):                      # предсказание и ошибка (11)
                pred = self.f(self.W[l](x[l+1]))
                eps[l] = x[l] - pred
            for l in range(1, L):                    # градиентный шаг по x_l (12)
                grad = self.W[l-1].weight.T @ eps[l-1]        # нисходящий член
                grad = grad * self.f(x[l])                    # нелинейность
                if l < L-1:
                    grad = grad - eps[l]                      # восходящий член
                x[l] = x[l] - eta * grad
        return x, eps
    def learn(self, x, eps, eta_w=1e-3):
        """Локальное правило (13): dW_l = eta * eps_l (x_{l+1})^T."""
        for l in range(len(self.W)):
            with torch.no_grad():
                self.W[l].weight += eta_w * eps[l].T @ self.f(x[l+1])
    def forward(self, data, T=25, eta=0.05, eta_w=1e-3):
        x, eps = self.infer(data, T, eta)
        self.learn(x, eps, eta_w)
        return x, eps

class SparseCoderLCA(torch.nn.Module):
    """Sparse coding (ур. 15-17): вывод — локально конкурентная динамика (17),
    обучение словаря — хеббовское правило (16). Без меток и градиентов."""
    def __init__(self, n_pix, n_atoms, lam=0.05, tau=10.0):
        super().__init__()
        self.Phi = torch.nn.Parameter(torch.randn(n_atoms, n_pix) / n_pix ** 0.5)
        self.lam, self.tau = lam, tau
    @torch.no_grad()
    def infer(self, I, T=200, dt=1.0):
        """LCA (15): b = Phi I; a_i обновляется пороговой динамикой."""
        b = self.Phi @ I                       # корреляционный отклик атомов
        G = self.Phi @ self.Phi.T              # грамиан ингибиции
        a = torch.zeros_like(b)
        for _ in range(T):
            resid = b - G @ a                  # остаток с учётом конкуренции
            support = resid.abs() > self.lam   # активное подмножество
            da = (-a + resid - self.lam * torch.sign(a)) / self.tau
            a = torch.where(support, a + dt * da, torch.zeros_like(a))
        return a

Листинг 4. Классический и современный Хопфилд: запись и ретрив
import torch
class HopfieldMemory:
    """Классическая (19)-(20) и современная (21)-(22) ассоциативная память."""
    def __init__(self, mode='classic', beta=1.0):
        self.mode, self.beta = mode, beta
        self.Xi = None          # матрица образов M x d
    def store(self, Xi):
        self.Xi = Xi
        if self.mode == 'classic':
            W = (Xi.T @ Xi) / Xi.shape[1]
            W.fill_diagonal_(0.0)
            self.W = W
    def retrieve(self, s, n_iter=25):
        if self.mode == 'classic':
            """Асинхронный спуск по энергии (20): доводит шумный ключ до ближайшего образа."""
            s = s.clone()
            for _ in range(n_iter):
                for i in torch.randperm(s.shape[0]):
                    s[i] = torch.sign(self.W[i] @ s)
            return s
        else:
            """Modern Hopfield (22): один шаг = attention-механизм."""
            logits = self.beta * (self.Xi @ s)         # энергии образов
            w = torch.softmax(logits, dim=0)           # веса по M образам
            return self.Xi.T @ w                       # новое состояние

import torch
class RingAttractor(torch.nn.Module):
    """Кольцо (24): 'мексиканская шляпа' держит бамп; нечётная добавка
    интегрирует угловую скорость (Zhang, 1996). Эйлер по tau."""
    def __init__(self, N=180, tau=10e-3, dt=1e-3):
        super().__init__()
        self.N, self.tau, self.dt = N, tau, dt
        phi = torch.linspace(0, 2*torch.pi, N)
        d = phi[None,:] - phi[:,None]                       # разности фаз
        # чётная часть: локальное возбуждение минус широкое торможение
        W_even = 1.0*torch.exp(-(d**2)/(2*0.3**2)) - 0.8*torch.exp(-(d**2)/(2*1.2**2))
        # нечётная часть: сдвиг бампа пропорционален скорости vel
        W_odd = 0.5 * (torch.roll(W_even, 1, dims=1) - torch.roll(W_even, -1, dims=1))
        self.register_buffer('W_even', W_even)
        self.register_buffer('W_odd', W_odd)
        self.register_buffer('r', torch.zeros(N))
    def step(self, vel=0.0, I_ext=None):
        """Возвращает бамп; vel>0 — вращение по часовой."""
        inp = self.W_even @ self.r + vel * (self.W_odd @ self.r)
        if I_ext is not None:
            inp = inp + I_ext
        self.r = self.r + self.dt / self.tau * (-self.r + torch.relu(inp))
        return self.r

весов, баланс E/I — то есть «обучение режимом» без функции потерь; в
ML-аналогии это гомеостатическая регуляризация, а не SGD. В reservoir
computing критичность реализована как «край хаоса»: вычислительная
мощность случайных рекуррентных сетей максимальна на границе
порядка и хаоса [60, 61] — критичность есть оптимальный режим
именно потому, что ляпуновский показатель ≈ 0: система хранит вход
достаточно долго, чтобы его обработать, и достаточно гибко, чтобы не
зациклиться.
6.4. Критика и границы применимости
Гипотеза критичности имеет и сильных оппонентов. Тубуль и
Дестексе показали [55], что чисто стохастические процессы без всякого
фазового перехода порождают степенные распределения, неотличимые
наивными тестами от лавинных, — «степенной хвост» сам по себе не
сертификат критичности. Дестексе и Тубуль далее продемонстрировали,
что две заведомо некритические модели проходят полный набор

import torch
def simulate_branching(sigma=1.0, T=200_000, p_ext=0.005, seed=0):
    """Гальтон-Уотсон (25): s_{t+1} | s_t ~ Poisson(sigma * s_t) + спонтанные.
    sigma<1 - вымирание; sigma=1 - критический; sigma>1 - взрыв."""
    g = torch.Generator().manual_seed(seed)
    s = torch.zeros(T)
    cur = 0
    for t in range(T):
        lam = sigma * cur
        cur = int(torch.poisson(torch.tensor(float(lam)), generator=g))
        if torch.rand(1, generator=g) < p_ext:
            cur += 1                     # редкий спонтанный триггер
        s[t] = cur
    return s

def avalanche_law(s, bins=25):
    """Лавины = всплески между нулями; проверка P(S) ~ S^-3/2 (25)."""
    sizes, cur = [], 0.0
    for x in s.tolist():
        if x > 0:
            cur += x
        elif cur > 0:
            sizes.append(cur); cur = 0.0
    if cur > 0:
        sizes.append(cur)
    S = torch.tensor(sizes)
    S = S[S > 0]
    hist = torch.histc(torch.log10(S), bins=bins)
    centers = torch.linspace(0, torch.log10(S.max()).item(), bins)
    sel = hist > 0
    slope = torch.polyfit(centers[sel], torch.log10(hist[sel]), 1)[0]
    return sizes, slope.item()   # slope ~ -3/2 в критической точке

8. Ограничения и контраргументы
Корпус, представленный выше, — это конструкции с явными
границами применимости, и честный обзор обязан их проговорить.
Во-первых, 
редукция 
сложности:

Во-вторых, эквивалентность предиктивного кодирования и backprop
точна только в специальном пределе — линейная f, транспонированные
обратные веса, стационарный вывод [24]; ослабления условий дают
приблизительное соответствие, а устойчивость обучения обратных весов
в нейронных реализациях остаётся активной проблемой (feedback
alignment и интернейронное обучение апикального прогноза частично
её решают [17, 18]).
В-третьих, аттракторная парадигма рабочей памяти сталкивается
с экспериментальной критикой: в ряде задач персистентная активность
отсутствует, а память поддерживается «безмолвно» — синаптическими
следами с быстрым восстановлением [62]; непрерывные аттракторы
требуют тонкой настройки (23), чувствительной к гетерогенности.
В-четвёртых, 
критичность: 
степенные 
законы

некритическими процессами [55], стандартные тесты дают ложные
срабатывания на контролах [59], и адекватная позиция — «около
критичности» с надлежащими несмещёнными оценками [56, 57].
Наконец, свободная энергия — мета-framework: она совместима со
многими

Инженерные обобщения из раздела 7 следует воспринимать как
гипотезы для бенчмарков, а не гарантированные выигрыши.
